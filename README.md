# 🧠 Personal Productivity & Burnout Risk Predictor

A Machine Learning mini-project built with Python, Scikit-Learn, and Streamlit. This application predicts a user's Productivity Score (Regression) and Lifestyle Category (Classification: Healthy/Balanced/Unhealthy) based on their daily habits.

## 📊 Dataset
The model is trained on the **Human Lifestyle & Daily Habits Dataset** (25,000 records, 28 features). It includes metrics like Sleep Hours, Screen Time, Exercise Days, and Stress Levels.

## 🛠️ Tech Stack
- **Data Processing:** Pandas, NumPy
- **Machine Learning:** Scikit-Learn (Random Forest Regressor, Random Forest Classifier, Gradient Boosting for CO4 comparison)
- **Frontend/UI:** Streamlit, Plotly (for interactive gauges)
- **Deployment:** GitHub
